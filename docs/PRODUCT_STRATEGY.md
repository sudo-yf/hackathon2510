# 产品战略（WayToAGI Gesture Control）

## 1. 产品使命

以最低学习成本，让普通用户通过自然手势完成桌面基础操作，降低键鼠依赖，提升演示与交互效率。

## 2. 目标用户

- 内容创作者：直播、录屏、教学演示
- 教学与科普场景：交互课程、实验课堂
- 轻量无接触控制场景：公共展示设备

## 3. 核心场景

- 场景 A：演示者在投屏时无需回到键鼠即可翻动/点击界面
- 场景 B：录制教程时保持镜头前连贯操作
- 场景 C：快速验证手势交互原型

## 4. 差异化定位

- 相比“纯算法 Demo”：强调端到端可运行体验（Web UI + 参数持久化）
- 相比“重型工业方案”：部署轻、上手快、改造成本低

## 5. 北极星指标（North Star Metric）

- 每日有效手势控制会话数（有效会话定义：连续运行 >= 3 分钟且完成 >= 30 次稳定指令）

## 6. 关键指标

- 首次可用时间（TTFV）：从 clone 到可用 <= 10 分钟
- 控制稳定率：有效帧中无抖动异常占比 >= 95%
- 手势触发准确率：>= 90%（标准光照条件）
- 异常恢复成功率：摄像头断连后自动恢复成功率 >= 95%

## 7. 产品路线

- V1（当前）：实时手势控制、参数调优、配置持久化
- V2：多手势可编程映射（自定义动作 -> 系统快捷键）
- V3：跨设备配置同步与场景模板
