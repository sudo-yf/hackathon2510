# 👋 手势控制系统 V2.0

基于 MediaPipe Hands 的实时手势识别鼠标控制系统，采用亚克力玻璃UI设计，支持高级鼠标映射算法。

## ✨ 核心特性

### 🎨 现代化界面
- **全屏相机视图** - 相机画面占据整个屏幕
- **亚克力玻璃效果** - 毛玻璃半透明UI组件
- **美观的手部骨架** - 蓝紫色渐变线条，21个关键点高精度识别
- **实时视觉反馈** - 手势状态、FPS、点击反馈

### 🖱️ 智能鼠标控制
- **取幂增稳-边缘加速** - 中心区域稳定，边缘区域快速
- **平滑移动算法** - 指数移动平均，消除抖动
- **死区过滤** - 减少微小抖动
- **可调参数** - 平滑度、中心增稳、边缘加速

### 👆 直观手势识别
- **食指移动** → 控制鼠标移动
- **拇指接触中指尖** → 左键点击
- **拇指接触中指中间** → 右键点击
- **防抖动机制** - 0.3秒冷却时间

- **5个核心手势** - 握拳、连续握拳、剪刀手、点赞、捏合

- **自定义快捷键** - 支持任意组合键（ctrl, shift, alt）

## 🚀 快速开始

### 1. 启动服务

**方式一：命令行**
```bash

```

**方式二：批处理（Windows）**

### 2. 访问界面
在浏览器中打开：
```
http://localhost:5000
```

### 3. 开始使用
1. 点击 **"📷 启动摄像头"**
2. 点击 **"🖱️ 启用鼠标"**
3. 将手放在摄像头前，开始控制！

### 4. 配置手势 ⭐ NEW!
1. 点击右上角 **"🎮 手势配置"**
2. 选择预设模式或自定义手势
3. 保存配置，立即生效！

### 核心算法

#### 取幂增稳-边缘加速
```python
# 中心化坐标
centered_x = norm_x - 0.5
distance = sqrt(centered_x^2 + centered_y^2)

# 中心区域：取幂减速（稳定）
if distance < 0.3:
    factor = (distance / 0.3) ^ power_factor
# 边缘区域：线性加速（快速）
else:
    factor = 1.0 + (distance - 0.3) * edge_boost

# 平滑处理
cursor_x = cursor_x + alpha * (target_x - cursor_x)
```

#### 手势检测
```python
# 计算欧氏距离
dist_to_tip = sqrt((thumb.x - middle_tip.x)^2 + (thumb.y - middle_tip.y)^2)
dist_to_mid = sqrt((thumb.x - middle_mid.x)^2 + (thumb.y - middle_mid.y)^2)

# 阈值判断
if dist_to_tip < threshold:  # 左键
    pyautogui.click()
elif dist_to_mid < threshold:  # 右键
    pyautogui.rightClick()
```

## 🐛 常见问题

### Q1: 启动失败，提示"无法打开摄像头"
**解决方案：**
- 检查摄像头是否被其他程序占用
- 关闭 Zoom、Teams 等视频会议软件
- 重新启动服务

### Q2: 鼠标移动不稳定
**解决方案：**
- 调高"平滑度"参数（0.6-0.8）
- 调高"中心增稳"参数（2.5-3.0）
- 确保光线充足

### Q3: 点击识别不准确
**解决方案：**
- 确保拇指和中指明确接触
- 保持手势 0.3 秒以上
- 调整摄像头角度
- 在手势配置中调节阈值 ⭐ NEW!

### Q4: FPS 过低
**解决方案：**
- 关闭其他占用 CPU 的程序
- 降低视频分辨率（修改代码）
- 更新显卡驱动
- 禁用不常用的手势 ⭐ NEW!

### Q5: 手势配置无法保存 ⭐ NEW!
**解决方案：**
- 检查 gesture_config.json 文件权限
- 确保JSON格式正确
- 查看浏览器控制台错误信息

### Q6: 手势频繁误触 ⭐ NEW!
**解决方案：**
- 提高手势识别阈值
- 增加冷却时间
- 禁用相似的手势

## 🎯 使用技巧

### 光线环境
- 确保光线充足且均匀
- 避免强烈背光
- 避免阴影遮挡手部

### 手部位置
- 距离摄像头 30-50cm
- 手部完全在画面内
- 避免遮挡脸部

### 手势姿势
- 手势要清晰明确
- 保持手势稳定
- 避免快速切换手势
